# Third-party reference material

## R package pomp

This benchmark uses the `blowflies1()` model and Nicholson population I data
distributed with the R package **pomp**, by Aaron A. King, Edward L. Ionides,
Carles Bretó, and the other contributors credited in its
[DESCRIPTION](https://github.com/kingaa/pomp/blob/7cfb3f9aa84c85de687b82d71b081016b9cc5762/DESCRIPTION).

The data in `data/nicholson_population_I.csv` are the unchanged table
distributed with the same model. The Python implementation follows its
process and measurement definitions.
