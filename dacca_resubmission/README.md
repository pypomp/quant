# Code for a revision of "Accelerated inference for partially observed Markov processes using automatic differentiation"

This code implements the results of Tan, Hooker and Ionides (2024), 
"Accelerated inference for partially observed Markov processes using automatic differentiation,"
<https://arxiv.org/abs/2407.03085>
using [Pypomp](https://github.com/pypomp/pypomp). 
The previous code, available at <https://github.com/hetankevin/diffPomp> and
<https://zenodo.org/doi/10.5281/zenodo.13356896>, was a precursor to Pypomp.

## DEPRECATED

Development of this article, and its source code, has moved to <https://github.com/pypomp/dmop>.
